# STORY-DASHBOARD-001

## User Story

As a logged-in admin,
I want to access the admin dashboard,
so that I can manage items, categories, and view system statistics.

## Acceptance Criteria

### AC1 — Dashboard Access
Given an admin user logged in
When the admin navigates to the dashboard
Then the dashboard displays the main navigation menu, stats overview, and recent activity

### AC2 — Add New Item
Given an admin on the dashboard
When the admin adds a new item with valid data
Then the item is created and appears in the items list

### AC3 — Add New Category
Given an admin on the dashboard
When the admin creates a new category
Then the category is created and available for item assignment

### AC4 — Dashboard Navigation
Given an admin on the dashboard
When the admin clicks on navigation menu items
Then the corresponding sections load correctly
